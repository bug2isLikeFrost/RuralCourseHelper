# 乡野课程助手 - 实现计划

## 项目概述
一款面向乡村教师的轻量级工具：通过输入本地事物（如竹林、稻田、腌菜、习俗等），AI自动生成跨学科课程方案。

## 核心功能
1. **输入本地事物**：文字描述 / 拍照上传
2. **AI生成课程**：输出4-6门跨学科课程卡片
3. **课程卡片展示**：卡片化呈现，可复制/分享

## 技术选型
- **前端**：单页HTML + CSS + JavaScript（零依赖）
- **AI接口**：调用通义千问/DeepSeek API
- **部署**：可直接在GitHub Pages/Vercel/Netlify免费托管

## 页面结构

### 页面1：启动页
- Logo + 标语："让乡野成为课堂"
- 2秒后自动跳转

### 页面2：主界面（输入页）
- 标题区域
- 输入框：多行文本，教师描述本地事物
- 可选：素材类型选择（植物/动物/食物/习俗/节气/其他）
- 生成按钮
- 加载动画

### 页面3：结果页（课程卡片展示）
- 展示4-6张课程卡片
- 每张卡片包含：
  - 课程名称（如"竹笋观察日记"）
  - 学科标签（语文/科学/数学等）
  - 适合年级
  - 核心知识点
  - 活动步骤
  - 延伸问题
- 重新生成 / 返回输入 按钮

## API设计

### 调用通义千问API
```
POST https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions
```

### 请求格式
```javascript
{
  model: "qwen-plus",
  messages: [
    {
      role: "user",
      content: prompt + "请根据以下本地事物生成跨学科课程方案：[用户输入]"
    }
  ]
}
```

### 响应解析
解析AI返回的JSON，提取课程卡片数据并渲染

## 提示词模板设计

```
你是一位乡村教育专家。请根据教师提供的本地事物，
生成4-6个跨学科课程方案。

输出格式（JSON数组）：
[
  {
    "学科": "语文",
    "课程名称": "竹笋观察日记",
    "适合年级": "3-4年级",
    "核心知识点": "观察描写顺序、修辞手法",
    "活动步骤": "1.带学生实地观察 2.描写竹笋...",
    "延伸问题": "竹笋长大后变成什么？"
  }
]

本地事物：[用户输入]
```
